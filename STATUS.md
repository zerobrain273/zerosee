# zerosee — состояние 0.2.0

## Реализовано

- `scan`: IPv4 TCP connect, диапазоны портов, RAII, дедлайны, пул потоков,
  короткие флаги и результаты OPEN/REFUSED/TIMEOUT/ERROR.
- `web URL`: libcurl GET, статусы, повторяющиеся заголовки, атрибуты cookies
  с редактированием значений, контролируемая цепочка перенаправлений.
- Scope: исходный origin плюс явные allow-origin, блокировка downgrade,
  циклов и лишних переходов. Proxy env/netrc не используются.
- HTTPS: проверка trust/hostname, CA bundle, connect-ip с сохранением SNI,
  метаданные цепочки, отсутствие insecure fallback.
- Контекстные наблюдения: TLS, HTTP, HSTS, HTML-заголовки, cookie-атрибуты,
  технологические подсказки. Нет автоматических заявлений о доказанных CVE.
- JSON schema_version 1 и экранированный Markdown, атомарное создание файлов
  с правами 0600 без перезаписи, отчёты в том числе об ошибках соединения.
- Локальные HTTP/HTTPS fixtures, автоматическая демонстрация и CI workflow.
- README и docs/architecture.md объясняют поведение, ограничения и структуру.

## Проверено в среде агента

- Debug-сборка GCC 16.2.1, libcurl 8.23.0, nlohmann/json 3.12.0 без предупреждений.
- 6 наборов CTest проходят: CLI, TCP-проба, пул потоков, web-unit, web-CLI,
  проверка лабораторной CA/hostname через OpenSSL.
- CLI: 10 тестов прошли, один реальный TCP-тест пропущен из-за запрета сокетов.
- В web_integration прошла офлайн-проверка CA/hostname; 7 сетевых тестов
  класса IntegrationTests не выполнялись из-за запрета сокетов.
- AddressSanitizer + UndefinedBehaviorSanitizer: доступные наборы проходят;
  detect_leaks=0, поэтому проверка утечек не заявляется. Те же сетевые пропуски.
- Python-файлы лаборатории и тестов компилируются.
- Пользователь ранее подтвердил реальные TCP OPEN/REFUSED. Это относится
  к TCP-части, не к новой HTTP/HTTPS-реализации.

## Проверка вне ограниченной среды

```bash
cd ~/Projects/zerosee
ZEROSEE_REQUIRE_NETWORK_TESTS=1 ctest --test-dir build -V
python3 lab/demo.py
```

Тесты сами создают и останавливают локальные HTTP/HTTPS-серверы. Demo сохраняет
четыре пары отчётов в reports/demo. Повтор: --output reports/demo-2.
Сетевую демонстрацию в среде агента запустить нельзя; её успешность не заявляется.
GitHub Actions настроен, но не запускался и проект не публиковался.

## Границы текущей версии

- `scan` и `web` запускаются отдельно; автоматический обход сайтов не реализован.
- web использует URL origin scope, не IP-allowlist; по умолчанию DNS.
- Нет эксплуатации, CSP-парсера полного стандарта, ревокации сертификатов,
  перебора шифров, воспроизведения сессий и автоматического CVE matching.
- JSON/Markdown пока только для web; сравнение снимков отложено.
- Shodan отложен по просьбе пользователя.
- Работаем только вдвоём: пользователь и Codex. Коммитов пока нет.

- Оформление: ASCII ZS2E, красная Z, остальные символы — цвет терминала;
  версия в подписи берётся из CMake. NO_COLOR и перенаправление отключают цвет.
